DecaFirma Delivery Routes

A batch of outgoing transfers is a delivery route: one DeCA for all the stops

Spanish road freight rules allow a single electronic control document (DeCA) for a whole delivery route when every stop has the same shipper and the same carrier (Resolution of 5 June 2026, section six). This module issues an Inventory batch transfer as that route in DecaFirma.

  • Plate, trailer and driver once, for the whole route.
  • One DeCA for the route, with its QR code on the batch and on every transfer.
  • Optionally, one delivery note per stop, signed on their phone by whoever receives the goods.
  • Added transfers to the batch? “Añadir las paradas nuevas a la ruta” issues the DeCA as a new version with the same QR code. Removed some? The route is updated too.

Data sent to DecaFirma

Nothing leaves Odoo until you enter your own DecaFirma API key in Settings. When a route is issued or updated, Odoo sends DecaFirma the data the DeCA requires for every stop: names, tax IDs (NIF) and addresses of your company, the customers, the carrier and the driver, vehicle plates, products, packages and weights.

Requirements

  • decafirma_stock (DecaFirma Inventory) and Batch Transfers (stock_picking_batch). This module is installed automatically when both are.
  • A DecaFirma account: the API is included in the 7-day free trial and, after it, in any plan with the Connection add-on. The module itself is free.
  • The user interface is in Spanish: the DeCA is a Spanish legal document.
